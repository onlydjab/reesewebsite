Publish

Your edits are saved in this browser only. To put them live, replace data/content.json in the repo.

  1. 1
    Download the updated file

    It downloads as content.json.

  2. 2
    Replace it in your repo

    On GitHub open data/content.json → pencil icon → paste the new contents → Commit. Or drag the file into the data/ folder to overwrite it.

  3. 3
    Wait about a minute

    GitHub Pages rebuilds automatically, then the live site shows your changes.

About dashboard security

          

            This login runs entirely in the browser, which is the trade-off for a site hosted free on
            GitHub Pages with no server. It stops casual visitors, but it is not real
            access control — someone who reads the page source can see the password hash.
          

          

            Never store anything sensitive here. If you need genuine protection, put the site behind
            Cloudflare Access (free) or move to a host with server-side auth. The README has steps.
